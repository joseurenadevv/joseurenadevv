## Proyectos destacados

<details>
<summary><b>🩺 Copayo — Bot de Telegram para estimación de copagos</b></summary>

<br/>

Proyecto desarrollado en equipo con **HELIX** para el reto de clasificación de **hackIAthon Panamá**.

Copayo estima el copago según el síntoma y sugiere el hospital más económico dentro de la red configurada.

| Dimensión | Detalles |
|---|---|
| **Stack** | n8n · Groq · Notion API · Telegram Bot API · JavaScript |
| **Pruebas** | 15 casos de prueba |
| **Casos adversariales** | 7 |
| **Cálculos** | JavaScript determinista |
| **IA** | Groq redacta la respuesta final |
| **Confiabilidad** | Procedimiento de rollback |
| **Repositorio** | [github.com/joseurenadevv/copayo](https://github.com/joseurenadevv/copayo) |

La decisión técnica principal del proyecto es separar la generación de lenguaje de la lógica económica: **el modelo no calcula montos ni decide precios**.

</details>
